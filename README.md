# GENERAL - جنيرال

أول نسخة تجريبية للعبة GENERAL على Android.

## بناء ملف APK
1. افتح تبويب **Actions** في المستودع.
2. اختر **Build GENERAL Android APK**.
3. اضغط **Run workflow** ثم **Run workflow** مرة ثانية.
4. انتظر حتى تنتهي عملية البناء بنجاح.
5. افتح نتيجة التشغيل، ثم قسم **Artifacts**.
6. نزّل **GENERAL-debug-APK** واستخرج ملف APK من ZIP وثبّته على هاتف Android.

## النسخة التجريبية الحالية
- شاشة أفقية.
- قرعة بداية بالنرد.
- لاعبان محليان بالتناوب.
- ثلاثة مسارات لكل لاعب: دبابة وطائرة ومدفع.
- 15 خطوة لكل مسار.
- رمية من 1 إلى 6 واختيار سلاح واحد لكل دور.
- إصابة السلاح المقابل عند الوصول إلى الخطوة 15.
- الفوز عند تدمير الأسلحة الثلاثة للخصم.

هذه نسخة أولية لا تحتوي بعد على الذكاء الخبير أو اللعب عبر الإنترنت أو الرسومات النهائية.
